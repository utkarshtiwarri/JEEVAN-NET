# JEEVAN-NET — Phase 1

Phase 1 is the frontend dashboard for the SIH 2026 JEEVAN-NET (ArogyaNexus) MVP.

## Included
- JEEVAN-NET dashboard
- Navigation for Patient Assessment, Emergency, Hospital Network and Patient History
- Healthcare network statistics
- Nearby facility intelligence mock data
- Symptoms → Actions pipeline
- Buttons ready to connect to later phases

## Run locally

Install Node.js (LTS), then open this folder in VS Code terminal:

```bash
npm install
npm run dev
```

Open the local address shown by Vite (usually http://localhost:5173).

## Next phase

Phase 2 will connect the Patient Assessment screen to actual patient inputs, a risk-scoring/ML backend, and the emergency triage flow.

> This is a hackathon prototype. It is not a medical diagnostic system.
